---
  title: "DocHeal"
  description: "Una aplicación web para programar citas con el médico, facilitando una comunicación fácil y eficiente entre pacientes y doctores."
  project_img: "../../../../public/assets/docheal-live.webp"
  github_repo: "https://github.com/EliasPereyra/docheal"
  live_link: "https://docheal.vercel.app/"
  summary: "Sacar un turno médico suele implicar llamadas, esperas y cargar los mismos datos una y otra vez. Con DocHeal, el paciente se registra, completa su información personal y médica una sola vez y pide el turno en pocos pasos. Cuando el médico lo confirma o lo cancela, le llega un SMS. Del otro lado, un panel de administración muestra todos los turnos y permite gestionarlos."
  key_features: 
    - "Registro con correo electrónico y contraseña"
    - "Registro de toda tu información personal y médica"
    - "Solicitar citas con el médico"
    - "Panel con todas tus citas"
    - "Un panel para el administrador donde puede gestionar la información y los turnos de los pacientes"
    - "Diseño responsivo para distintos tamaños de pantalla"
  design_goals: 
    - title: "Que la API key nunca llegue al navegador"
      description: "Todas las operaciones con Appwrite corren en Server Actions de Next.js con el SDK de Node, así la API key nunca llega al navegador."
    - title: "Un backend resuelto para enfocarme en la UX"
      description: "La base de datos, el almacenamiento de archivos y el envío de SMS los resuelve un BaaS. Eso me dejó concentrarme en la experiencia del paciente y del admin."
    - title: "Formularios largos sin errores al enviar"
      description: "React Hook Form y esquemas de Zod dan feedback al instante en formularios largos, como el de datos personales y médicos."
    - title: "Gestionar turnos y avisarle al paciente"
      description: "Los turnos se listan en una tabla con su estado (agendado, pendiente o cancelado) y acciones para confirmarlos o cancelarlos, lo que dispara el SMS al paciente."
